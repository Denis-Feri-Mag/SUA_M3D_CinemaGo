# Notes for AI tools

This is a student microservices project.

- Follow docs/CONVENTIONS.md (health endpoint, swagger, env variables, error format)
- Don't add new frameworks or big dependencies without asking

## Who owns what

Owners and their git users are in the services table in [README.md](README.md#services).

## Editing other people's code

- Run `git config user.name` to see who you are working for and find their folders in that table
- If the name is not in the table, ask the user who they are
- If a change touches a folder owned by someone else, warn the user first and say whose folder it is
- Only continue if the user confirms, and mention it in the PR so the owner can check it
